Intelligence artificielle

L'IA de l'appli est Google Gemini, gratuite. Chacun utilise sa propre clé.
Gratuite : va sur aistudio.google.com/apikey, connecte-toi avec un compte Google, clique sur « Create API key », copie-la ici. Avec l'offre gratuite, Google peut utiliser tes requêtes pour améliorer ses modèles : n'importe pas de documents personnels sensibles.
Ta clé est enregistrée dans ton compte ; les autres utilisateurs ne peuvent pas la voir.
